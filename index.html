AI 总控接入

对话框现在是一个真 Agent：能多轮对话、缺字段会追问、通过工具调用起草 13 个区的记录。界面和写入规则已经定死，接模型只换一个函数。浏览器静态页不能放密钥，附带的 ai-proxy.js 跑起来后同源托管页面，接口地址填 /chat 即可。

接入模型
A
最快：复制提示词 → 问任何 AI → 粘回来（不用密钥、不用装东西）
① 点上面的复制 AI 提示词 → ② 发给 WorkBuddy 或任意 AI，再补一句今天的事 → ③ 把 AI 回的整段 JSON 粘进底部对话框 → ④ 起草卡里点「确认写入」。
B
全自动：让本机小服务替网页调模型（连粘贴都不用）
① 点复制启动命令，在终端粘贴运行一次（需要 Node 18+ 和你的模型 key） → ② 打开http://localhost:8787 → ③ 模式选「云端模型」、地址填/chat、点保存 → ④ 以后在底部说话，它会追问缺的字段、直接起草，仍需你点头才落盘。
C
MCP：在任何支持 MCP 的 AI 里说话就写进来 —— 最彻底，但要先把数据从浏览器搬到云端，和当前 A 方案冲突，等要做多设备同步时再上。点「复制 MCP 工具清单」可先拿到全部工具定义。
现在没配 key 也能完整试用 Agent：模式留「本地演示」，说「押注：这事一周内有回音」，它会依次追问到期日、那个数在哪、具名反方——补齐才让你确认，这就是 Agent 的追问能力。
接口协议（给写代理的人看）
前端 POST {"messages":[{"role":"user","content":"…"}],"tools":[…],"system":"…","context":{"counts":{…}}} 到 /chat；服务端跑工具调用循环，返回 {"reply":"…","ops":[{"m":"L0","rec":{…}}],"notes":[]}。ops 只是草稿，网页会再跑一遍硬规则，你点头才落盘。附带的 ai-proxy.js 已实现这套协议，支持任何 OpenAI 兼容端点（需支持 function calling）。旧的单轮 /parse 仍兼容保留。

这套系统在防什么

① L5 审计 L0–L4 全部，也审我自己。点顶栏 ▦ 进审计台，能看「还要做的项目」清单。
② L4 是唯一产生价值的地方——同类判例凑够 3 条才允许提炼算法，其余区都是供料和兜底。
③ 外部验收人空着 = 整套没有出口。必须是一个敢当面说你美化了的真人，不能是自己、不能是 AI。

硬规则清单

触感与光影反馈

全部用浏览器自带能力做的，没有引入任何外部插件：震动走手机 Vibration API，提示音是浏览器即时合成的，胞体光照和树突是 CSS / SVG。

画布操作

神经元可自由拖动摆放（自动保存），放大到 100% 以上才拖空白处平移、Ctrl + 滚轮缩放（100% 及以内视图保持固定不晃）；⌗ 整理布局、⤾ 复位节点、↺ 复位视图。悬停胞体会放大并浮出该区说明，缺口节点有红色呼吸环。
